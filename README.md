Um site de notícias desenvolvido utilizando HTML5 e CSS3, com foco em estrutura semântica, organização visual e layout responsivo.

**Tecnologias e Ferramentas Utilizadas**
```
HTML5 – Estrutura e semântica
CSS3 – Estilização e responsividade
Figma – Criação do protótipo e design da interface
Vercel – Deploy e hospedagem do projeto
```
**Funcionalidades**
```
📰 Seção de notícias em destaque
📂 Organização por categorias
📱 Layout responsivo
🎨 Design limpo e organizado
```
